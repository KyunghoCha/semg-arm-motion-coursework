# 로컬 GPU 실험 사전 계획

작성: 2026-10-20 15:09 UTC. 실제 데이터 학습·새 시험 예측 전에 고정.

## 목적과 비교 단위

8명·5채널·4동작 × 2각도의 8클래스를 대상으로 기존 CPU 실험과 같은 분할에서 신경망을 검증한다. A는 기존 51/13 기록 분할, B는 각 기록 시행 1–24/25–30 분할이다. 기존 `split.npz`의 개발/시험/5폴드 인덱스를 그대로 사용한다. A는 기록이 분리되고, B는 시행이 분리되지만 같은 기록의 조건을 학습할 수 있다. 둘 다 새로운 사람 일반화 평가가 아니다.

전체 원자료는 고정 manifest에 대조한다. 제공된 bandpass 신호에 추가 필터를 적용하지 않는다. 기존 라벨 없는 에너지 정렬 규칙(0.5–3.5초 후보, 0.1초 이동, 최대 합산 제곱 에너지, 최초 최대값)을 그대로 재계산하고 기존 `peak_start/window_start`와 일치시킨다. 마커가 실제 동작 시작이라는 가정은 하지 않는다.

## 후보와 선택 규칙

동일한 에너지 정렬 1초 구간을 사용하며 두 비교를 구분한다.

1. `raw200`: 각 200ms 창의 5채널 원파형. 채널별 시간 합성곱 후 채널 혼합, 평균·최대 풀링과 로그 RMS 보조 입력을 결합한 소형 1D CNN.
2. `spectral200`: 동일 200ms 창 내 64샘플 Hann 프레임, 16샘플 이동의 log-power STFT. 채널×주파수 축을 입력 채널로 사용한 소형 시간 CNN.
3. `raw1000`: 같은 1초 구간 전체를 입력한 raw200 구조. 시행을 직접 분류.
4. `spectral1000`: 같은 1초 구간 전체의 STFT 시간 CNN. 시행을 직접 분류.

200ms 후보의 입력 표본·분할·창 위치는 CPU 기준선과 동일하다. 시행 예측은 9개 창 다수결(동률 최소 클래스)로 비교한다. 1초 후보는 모든 시행에 대해 한 예측을 내며 CPU의 1초 안의 9개 창 다수결과 같은 원신호 범위를 사용한다. 다만 모델의 시간 문맥·학습 단위·집계 방식이 달라, 이를 순수 GPU 효과로 설명하지 않는다. 1초 모델에 window 정확도를 만들어 붙이지 않는다.

각 분할에서 200ms 후보 중 하나, 1초 후보 중 하나를 각각 5폴드 평균 macro-F1로 선택한다. 동률이면 후보명 사전순. 200ms는 window macro-F1, 1초는 trial macro-F1로 선택한다. 시험 결과는 두 선택을 모두 고정한 다음 한 번 평가한다. 기존 시험 점수는 이미 알려져 있으므로 독립 확증시험이라는 주장을 하지 않는다.

## 학습 설정

- 기존 Python3.10 + PyTorch2.6.0+cu118; GPU FP32. 패키지 설치 없음.
- CV seed=42, 폴드별 seed=42+fold. 최종 학습 seed=42와2026을 미리 고정하고 두 모델의 softmax 확률을 평균하는 앙상블을 최종 예측으로 사용한다. 각 seed 결과도 모두 기록하며 좋은 seed를 고르지 않는다.
- AdamW, learning_rate=0.001, weight_decay=0.001, batch_size=128, dropout=0.25, label_smoothing=0.05, gradient norm cap=5.
- 최대 40 epochs, 최소 8 epochs, 검증 macro-F1의 개선이 8 epochs 없으면 조기 중단. 동점은 처음 epoch 유지. 손실·정확도·macro-F1·GPU 메모리를 매 epoch 기록.
- 최종 epoch 수는 선택 모델의 5개 best_epoch 중앙값을 반올림하여 고정한다. 시험은 epoch/후보/seed 선택에 사용하지 않는다.
- 입력 평균/표준편차 또는 RMS scale은 해당 학습 폴드에서만 계산한다. 시험 기록 전체를 이용한 정규화, 사람/기록 ID 입력, 전극 재배열 없음.
- CUDA/cuDNN 결정적 알고리즘을 요청하고 RNG를 고정한다. 다른 버전·하드웨어의 bitwise 동일성은 보장하지 않는다.

## 사전 점검과 중단 기준

- 64기록, 기록당30마커, 8명, 8클래스, 채널5개, 유한 수치, 시간 간격1ms, 라벨 매핑, 원자료 해시, 마커 간격과 시행 경계를 검사한다.
- 원파형에서 25특징을 재계산해 제공 peak_energy1s70의 앞25열과 허용 수치 오차 내 일치 여부를 검사한다.
- 모든 시행의 창이 같은 분할·폴드에 속하고, 다른 시행의 원신호 구간이 겹치지 않는지 assert한다. 입력 정렬은 전체 시행을 필요로 하므로 온라인 지연 성능을 주장하지 않는다.
- 학습 코드 합성자료로 출력 shape, finite loss/gradient, checkpoint 재로딩 일치, 작은 표본 overfit을 점검한다.
- NaN/Inf, 해시/분할/라벨 불일치, 예상 밖 경로 쓰기, GPU 온도85°C 이상, 여유 디스크5GB 미만이면 중단한다.
- GPU 1개, CPU 최대4스레드, 모델 가중치 최대250k 파라미터, 학습 프로세스 peak VRAM8GB 이하, 초기 전체 학습 예산90분. 다른 사용자 프로세스를 종료하지 않는다.
- OOM이면 batch_size만64로 낮추어 해당 실행을 처음부터 재시도하고 변경을 기록한다. 모델/선택 기준을 시험 성능에 따라 바꾸지 않는다.
- 복구 가능한 구현 오류는 고친 뒤 영향을 받은 실행만 다시 수행하고 원래 실패 로그를 보존한다. 예산 초과 시 완료 후보만으로 몰래 선택하지 않고 미완료 항목을 보고한다.

## 전달할 근거

모든 후보의 검증 결과와 epoch 로그, 선택 이전 JSON, 두 seed checkpoint, 최종 예측, 클래스별/기록별 점수, window/trial 혼동행렬, 고정 CPU 기준선 비교, 원자료·코드·설정 해시, 재실행 명령을 제공한다. A/B를 별도 표로 제시하고 B 개선을 A 개선으로 표시하지 않는다.
