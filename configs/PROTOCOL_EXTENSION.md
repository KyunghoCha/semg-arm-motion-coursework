# 검증 결과를 반영한 보완 실험

2026-10-20 15:19 UTC. 1차 개발 CV 일부 완료 후, 새 시험 예측 전 작성.

## 변경 근거

A의 5폴드 검증 평균 정확도는 raw200 23.16%, spectral200 23.99%, raw1000 33.39%, spectral1000 37.88%였다. 학습 정확도가 증가하는 동안 검증 점수는 조기에 하락했다. A의 spectral1000 최적 epoch는 [2,2,2,6,15]였다. 기록 간 진폭 차이와 모델 과적합 가능성을 검토할 필요가 있다. B의 spectral200은78.05%로 raw200의58.48%보다 높았다. 이 관찰은 개발 데이터에서 얻었다. 1차 시험 평가를 실행하지 않고 최종 선택을 보완 실험 종료까지 보류한다.

## 추가 후보

동일한 원자료·창·시행·5폴드를 사용한다.

- `spectral_relative200`, `spectral_relative1000`: 각 입력 표본의 전체 채널·주파수·시간 log-power 평균 하나를 빼서 공통 진폭 수준을 제거한다. 각 채널을 따로 정규화하지 않아 채널 간 상대 크기는 유지한다. 그 다음 학습 폴드로만 채널×주파수 평균/표준편차를 맞춘다. 외부 기록 통계는 사용하지 않는다.
- `spectral_aug200`, `spectral_aug1000`: 기본 STFT 입력을 유지한다. 학습 때 표본별 공통 ln-gain~N(0,0.30²)과 채널별 ln-gain~N(0,0.15²)을 더하고 이를 log10 power에 맞게 변환한다. 검증·시험에는 증강을 쓰지 않는다. 동작 정보를 과하게 지울 위험이 있으므로 기본 모델을 후보에 유지한다.

추가 CNN의 나머지 구조·최대40epoch·조기중단·seed·자원 한도는 원 계획과 같다. 원래 네 모델과 보완 네 모델 중 입력 길이별·평가별 평균 CV macro-F1 최고를 선택한다. 이전 `SELECTION_LOCK.json`은 1차 내부 선택 기록으로 보존하고, 모든 후보를 포함한 `FINAL_SELECTION_LOCK.json`을 새 시험 예측 전에 저장한다. 선택/코드 해시는 보존한다.

## 같은 1초 문맥의 CPU 대조군

입력은 기존 peak_energy1s70의 9개 창이다. 앞15개 진폭 특징을 기존 방식대로 log10 변환한 후, 시행 내 특징별 평균만 쓰거나 평균과 표준편차를 연결한다. 표본당70/140차원이며 순서 정보는 없다.

- 평균 벡터: RBF SVM C=0.1/1/10, gamma=scale.
- 평균+표준편차 벡터: RBF SVM C=1/10, gamma=scale.
- StandardScaler는 학습 폴드로만 fit.
- 5개 후보 중 시행 단위 CV macro-F1로 평가별1개 선택 후 고정 시험 평가.

이 대조군은 GPU 사용과 시간 문맥 증가의 효과를 구분한다. 동일 원신호 범위라도 학습 단위·표현이 달라 기존200ms 단위 점수와 혼동하지 않는다. 새로운 설치 없이 기존 Conda base의 SVM을 사용한다.

## 선택 편향과 종료

이번 보완은 개발 CV를 본 후 정한 적응적 탐색이며 CV 자체를 편향 없는 최종 성능으로 해석하지 않는다. 기본/보완 총8개 CNN 후보 ×2평가 ×5폴드, CPU대조군5후보 ×2평가 ×5폴드를 모두 보고한다. 이후 새로운 후보를 추가하지 않고 검증 선택을 고정한다. 최종 시험을 본 후 튜닝하지 않는다. 계획된 GPU 연산은 기존90분 범위 안에서 완료하도록 한다.
