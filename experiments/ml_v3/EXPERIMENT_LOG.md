# 전체 실험 과정

모든 수치는 A 개발 기록의 같은 5겹 검증이다. F1은 8클래스 macro-F1의 폴드 평균이다.
채택은 개발 기준의 대표 선택을 의미한다. 기존 A/B 시험 성능의 채택·기각을 의미하지 않는다.
원본 코드와 후보별 config·로그·예측은 각 링크에서 확인할 수 있다.

## `legacy_svm1`

- 관찰·가설: 기존 CPU 특징과 평가를 재현하는가.
- 변경·고정 조건: legacy→legacy; SVM C1 고정. 같은 1초·기록5겹·학습 폴드 통계.
- 비교 기준: `legacy_svm1`. 상세 설정은 [fold0 기록](artifacts/results/screen/legacy_svm1/fold0/summary.json).
- 결과: 정확도 21.24 ± 2.38%, F1 0.1961, 각도 35.77%, 5회 fit 합계 0.31초.
- 해석·결정: 기준과 같은 개발 평균 F1이었다(차이 +0.0000). 비교 근거로 보존; 1초 대표에는 미선택.
- 다음 선택: 고정한 검증·민감도 진단으로 확인하며 이 평가 후 후보를 조정하지 않는다.
