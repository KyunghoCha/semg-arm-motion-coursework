# 선택 고정 후 분할 민감도 진단

초기57종과 보충22종을 모두 비교한 뒤 대표 모델을 잠근다. 기존8클래스
SVM C1, 초기57종 대표, 전체79종 중1초 대표,5초 문맥 대표를 고정하여
아래 분할 진단을 수행한다. 이름이 같으면 중복 학습하지 않는다.
진단 결과로 후보·특징·파라미터를 바꾸거나 대표 모델을 다시 고르지 않는다.

- A 개발51기록에서 새 층화 기록5겹을 seed20261022/20261023으로 각각 생성한다.
  동일 시행과 기록은 폴드를 넘지 않는다. 변경된 기록 구성에 대한 민감도를 측정한다.
- 같은 개발 자료에서 참가자a–h를 한 명씩 제외한다. 학습에서 그 사람의 모든
  개발 기록을 제외하고 해당 사람의 개발 기록만 평가한다.
- 각 진단은 고정 모델의 정확도, macro-F1, 손동작·각도 정확도와 폴드 변동을 보고한다.
  참가자별 제외 평가에는 클래스가 빠진 사람이 있으므로 폴드별8클래스F1과
  전체예측을 합친F1을 구분하고 평균 정확도를 주로 비교한다.

**선택 독립성을 갖춘 새 시험은 아니다.** 후보 설계와 대표 선택에 이 참가자들의
기존 개발 결과를 사용했다. 이 진단의 목적은 그룹 구성 변경 시 성능 변동을
확인하는 것이다. 기존 A/B 시험 입력·정답·예측에는 접근하지 않는다.
원래23종의 중첩 모델 선택 절차와 이 고정 모델 진단도 구분한다.

분할 생성, 참가자 목록과 대표 이름은 실행 전에 별도JSON과SHA-256으로 고정한다.
같은 환경·CPU2thread·원래 시간 예산을 사용한다. 새 튜닝이나 후보를 추가하지 않는다.
