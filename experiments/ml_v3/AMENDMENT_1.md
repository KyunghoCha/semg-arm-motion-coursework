# 독립 손동작·각도 모델의 요인별 비교

첫57후보의 개발5겹 비교 후, 중첩 외부 결과를 보기 전에 작성했다.
결합 특징의8클래스 ExtraTrees는22.88%, 독립 구조는44.59%,
계층 구조는24.80%였다. 독립 구조의 각도 정확도는51.73%로 제한적이었다.
축소LDA는robust35.27%, legacy34.85%였고 F상위64개+SVM은30.74%였다.
이 결과는 분류 구조와 규제의 영향을 따로 비교할 근거가 된다.

## 질문과 후보

1. 독립 구조 이득이 결합 특징에 의존하는가?
   동일ExtraTrees leaf3를 legacy/robust/spectrum/relations/relative에서
   독립 구조로 비교한다. fusion의 이미 끝난 결과는 재실행하지 않는다.
2. 과적합을 줄이는 모델에서도 유지되는가?
   독립LDA를6특징군, 독립SVM C1을legacy/fusion에 적용한다.
   SVM은 두 분류기의 정답 예측을 `2×손동작+각도`로 조합한다.
   저장용 margin softmax는 보정 확률이 아니며 앙상블 후보에서 제외한다.
3. 트리 복잡도·가중치의 영향인가?
   fusion 독립ExtraTrees leaf6와 무가중치 leaf3,
   독립RF leaf3를 기존 독립ExtraTrees와 대조한다.
4. 각도에 필요한 채널·진폭 정보가 다른가?
   손동작은legacy ExtraTrees를 고정하고, 각도는LDA로
   5채널 logRMS, CH4·5 logRMS, CH4·5 logRMS와차이,5채널 상대logRMS를 비교한다.
5. 표본 안의 진폭 기준이 도움이 되는가?
   같은 손동작 모델에, 각도만 표본별5초의 낮은 진폭 기준에 대한1초RMS차이를
   LDA/ExtraTrees로 학습한다. 기준은각 채널50개100ms logRMS의20백분위수다.
   이것은 확인된 생리적 휴식 구간이 아니다. **5초 문맥을 추가하는 별도 입력 조건**으로
   표시하고1초 비교와 분리한다. 원시5초를 다시 읽거나 시험 통계를 fit하지 않는다.

총22개 추가 후보를 개발5겹에서 비교한다. 모든 정규화·모델 fit은학습 기록만 사용한다.
원래23개 중첩 후보군과 외부 평가 규칙은 변경하지 않는다.
추가 후보는적응적 개발 결과로만 보고하고 기존A/B시험에서는 평가하지 않는다.
조정 요소가 여러 개인 혼합 분류기는 탐색으로 표시하며 동일 손동작 모델의 각도
입력 비교를 요인별 대조로 제공한다. 전체 예산을 공유하고 동일 실행을 반복하지 않는다.

외부 결과를 연 뒤에는추가 후보를 만들지 않는다. 이 묶음이 끝나면 개발 상승폭,
각도 정확도, 기록별 변동, 중첩 절차의 결과를 함께 보고하여 추가 정보가 필요한지
판단한다. 근거 없는파라미터 격자 확대는 수행하지 않는다.
