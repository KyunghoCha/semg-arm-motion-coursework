# 팔 동작 분류 추가 실험

전체 과제와 추가 탐색의 흐름은 [루트 README](../README.md)에서 표·그림과 함께 읽을 수 있다.

기존 공개 결과를 보존한 상태에서 진행한 추가 실험이다. 원래 메인 README와 결과는
커밋 `264f38a38246308235b30fbe77a0be7bb21f54cd`에 해당한다.
추가 실험은 로컬 `research/generalization-v2` 브랜치에 정리했다.

두 보고서에는 입력·분할·선택 규칙, 모든 후보의 결과와 실패, 혼동행렬, 실행 코드와
재현 절차를 포함했다. 신경망 학습은 사용자 PC의 TITAN Xp에서, 전통 머신러닝은
같은 PC의 기존 CPU 환경에서 실행했다. 새 패키지를 설치하지 않았다.

| 단계 | 확인한 결과 | 보고서 |
|---|---|---|
| GPU 모델 추가 비교 | 개발에서 선택한 CNN의 기존 A 시험 정확도가 50.51%에서 45.64%로 하락 | [GPU·강의 기준 실험](generalization_v2/README.md) |
| 전통 ML 중심 탐색 | 개발 기록 5겹에서 기존 집계 SVM 21.24%, 독립 LDA 54.65% | [ML 비교와 진단](ml_v3/README.md) |
| ML 고정 23종 중첩 선택 | 같은 개발 자료의 외부 기록 5겹에서 SVM 21.24%, 내부 선택 절차 40.52% | [중첩 평가](ml_v3/README.md#6-고정-23종의-중첩-평가) |
| 강의 기준 C | 동일 기록 내 무작위 시행 5겹에서 RF의 시행 다수결 96.20±0.89% | [강의 기준 C 결과](generalization_v2/README.md#8-강의-기준-c-결과) |

ML 개발 수치는 기존 A 시험 성능과 직접 비교할 수 없다. C 역시 기록 분리 A와
평가 대상이 다르다. 논문 전문의 정확한 입력·분할·집계 조건은 아직 확인하지 못했으며,
논문 수준 달성이나 독립적인 신규 기록·참가자 일반화를 확인한 결과는 아니다.

[79개 ML 후보의 과정 기록](ml_v3/EXPERIMENT_LOG.md)은 관찰과 가설, 변경한 조건과
고정한 조건, 비교 기준, 결과와 변동, 채택·기각 이유를 후보별로 보여준다.
기존 A/B 시험은 ML 단계에서 다시 평가하지 않았다.

검토용 `artifacts/`에는 설정·예측·집계·로그·그림을 넣었다.
원신호, 특징 행렬, 학습 모델, 강의 원본은 포함하지 않았다.
실제 데이터 재구성과 학습은 각 보고서의 재현 절차와 기존 저장소 코드를 사용한다.
이번 추가 실험은 원격 저장소에 게시하지 않았다.
