# XGBoost 개발 비교 계획

실제 과제의 XGBoost 결과를 계산하기 전에 이 계획·코드·입력 해시를 고정한다. 기존 A/B 시험은 열지 않는다. 목표는 기록이 바뀔 때 나타나는 각도 식별 오류가 부스팅과 분류 구조에 따라 줄어드는지 확인하는 것이다.

## 관찰과 가설

기존 개발 비교에서 결합 특징의 직접 LDA는 30.97%, 손동작·각도 독립 LDA는 54.65%였다. 독립 LDA도 각도 정확도는 58.84%였고 학습 정확도는 97.21%였다. 비선형 경계를 학습하는 부스팅이 독립 구조와 함께 도움이 될 수 있지만, 기록의 특성을 외우면 오히려 일반화가 나빠질 수 있다. 특징군, 구조, 트리 깊이를 교차하여 이 요인을 구분한다.

## 고정 입력과 후보

- A 개발 51기록·1,530시행만 사용한다. `ml_v3`에서 생성한 1초 에너지 정렬 특징과 동일한 기록 5폴드·외부별 내부 3폴드를 사용한다. 입력 해시와 원 A 시험 인덱스 제외 여부는 기존 검사와 대조한다.
- 특징 4종: 기존 요약 140개, 분포 요약 280개, 결합 395개, 상대량 320개. 별도 표준화·특징 선택을 하지 않는다. 특징 추출 규칙은 고정이며 검증 자료에서 통계를 학습하지 않는다.
- 구조 2종: 8클래스 직접 분류, 4손동작·2각도 독립 분류. 독립 확률은 두 확률의 곱으로 8클래스를 구성한다.
- 깊이 2·4·6을 교차하여 24종을 만든다. 나머지는 200라운드, eta=0.05, min_child_weight=5, lambda=5, subsample=0.8, colsample_bytree=0.8, max_bin=128, seed=20261024로 고정한다. 학습 헤드별 클래스 균형 가중치는 해당 학습 행의 라벨 빈도로만 계산한다.
- 공식 PyPI XGBoost 3.0.5, CUDA `hist`, GPU 1개, CPU 2스레드로 순차 실행한다. Python 3.13.9의 별도 venv에서 설치했으며 기존 base 패키지는 변경하지 않았다. 설치·GPU 확인 자료는 별도 환경 기록으로 보존한다.

## 선택과 평가 순서

1. 합성 자료의 직접/독립 구조, CUDA 장치, 확률 합, 저장·복원, 분할 불변 조건을 검사한다.
2. 24종 각각 동일 기록 5폴드에서 개발 결과를 계산한다(120회). 8클래스 macro-F1의 폴드 평균으로 대표를 선택하고 동점은 이름순으로 결정한다. 정확도, 손동작/각도 정확도, 학습·검증 차이, 시간은 보조 지표다.
3. 외부 각 5폴드의 학습 부분 안에서 내부 3폴드×24종을 비교한다(360회). 모든 외부 폴드의 선택을 파일에 잠근 뒤 외부 5개를 학습·평가한다. 24종 선택 절차의 점수이며, 5폴드 전체에서 고른 단일 대표의 점수와 구분한다.
4. 대표를 고정한 뒤 기존 ML의 두 기록 재분할(각 5폴드)과 참가자 8명 제외 조건에서 진단한다(18회). 진단 뒤 후보나 대표를 바꾸지 않는다. 신규 독립 시험이 아니라 개발 자료의 선택 후 민감도 분석이다.
5. 대표를 전체 개발 자료로 학습한 모델 1개를 로컬에 보존한다. 이 모델의 학습 정확도를 일반화 성능으로 보고하지 않는다. 총 504회이며 독립 구조에서는 하위 모델 두 개를 학습한다.

라운드 수는 검증 곡선을 보고 조정하지 않는다. 모든 곡선은 고정 학습의 진단용이다. 이번 후보군은 사전 고정 24종으로 종료하고 외부/참가자 진단 결과를 이용한 추가 튜닝을 하지 않는다. 기존 LDA·SVM 및 고정 23종 선택 절차와 같은 분할에서 비교하되, 과거 개발 결과를 본 설계 이력과 후보군 차이를 명시한다. 이번 중첩 검증도 새 자료의 독립 평가를 대신하지 않는다.

## 자원·중단·재현

GPU 1작업·CPU 2스레드, 단계당 최대 60분, 전체 추가 학습 90분을 상한으로 둔다. 예상 경과시간은 15–25분이며 첫 완료 로그로 갱신한다. 온도 85°C 이상, 여유 디스크 5 GiB 미만, 다른 연산 작업과의 충돌, 비유한 값, CUDA 미사용 또는 코드/분할/입력 해시 불일치 시 중단한다. 각 완료 학습은 예측·곡선·지표와 시간을 원자적으로 기록하여 재시작 시 건너뛴다. 실패도 원인과 시각을 보존한다. 외부 모델과 대표 모델은 로컬 UBJ로만 저장한다.

원신호·특징 행렬·모델·강의 원본·인증정보·개인 대화는 공개하지 않는다. 공개 자료는 코드, 계획, 분할 식별자, 예측·집계 결과·그림과 실행 로그다. 실패한 후보를 포함하여 관찰→가설→변경 조건→검증→결과→해석을 보고서에 남긴다.
