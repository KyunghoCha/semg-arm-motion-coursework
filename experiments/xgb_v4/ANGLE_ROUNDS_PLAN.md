# 각도 학습량을 분리하는 개발 후속 비교

## 추가 이유와 이미 본 결과

고정 24종의 학습·중첩 평가·선택 후 진단을 완료한 뒤 대표의 개발 학습 곡선을 확인했다. 손동작 검증 로그 손실은 200라운드까지 감소했지만 각도 검증 손실은 초기에 감소한 후 증가했다. 이 개발 곡선은 두 헤드의 학습량을 분리할 근거를 제공한다. 고정 24종 결과와 선택은 그대로 보존한다.

이 후속 비교 전에 XGBoost 개발 52.24%, 중첩 선택 46.70% 및 참가자 진단을 이미 보았다. 따라서 아래 결과는 누적 분석 뒤 추가한 개발 탐색이며 독립 평가가 아니다. 기존 A/B 시험, 중첩 외부 평가와 참가자 진단을 다시 실행하지 않는다.

## 고정 비교

기존 4개 특징군 모두에 깊이 2의 독립 XGBoost를 적용한다. 손동작은 200라운드로 유지하고 각도 라운드만 10·25·50·100으로 바꾼다. 16종×같은 개발 기록 5폴드=80회다. 각 특징군의 양쪽 200라운드 결과는 완료한 고정 비교에서 그대로 가져온다. 나머지 파라미터, 학습 클래스 가중치, 난수와 데이터·분할은 동일하다.

8클래스 macro-F1의 개발 5폴드 평균으로 이 후속 후보와 기존 네 독립 깊이 2 후보를 비교한다. 동점은 이름순으로 선택한다. 선택 결과는 기존 독립 LDA의 개발 결과와 같은 조건에서 비교하되 최종 모델의 외부 성능으로 제시하지 않는다. 이 단계에서 새 외부 평가나 대표 전체 학습은 하지 않는다.

코드·계획·입력 해시를 첫 실행 전에 기록한다. 예상 1–3분, 최대 15분, GPU 1개·CPU 2스레드로 수행한다. 온도 85°C 이상·여유 공간 5 GiB 미만·비유한 값·CUDA 미사용·해시 불일치 시 중단한다. 결과에 따라 범위를 더 잘게 나누는 추가 탐색은 이번 묶음에 포함하지 않는다. 변화가 있더라도 새로운 독립 검증이 필요한 개발 결과로 정리한다.
