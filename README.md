# Step2 — sEMG 손동작·팔꿈치 각도 분류

이 과제는 5채널 표면 근전도(surface electromyography, sEMG)로 손동작 4종과 팔꿈치 각도 2종의 조합, 총 8개 클래스를 분류한다. 같은 기록의 반복 시행에서는 높은 정확도가 나왔지만, 기록을 바꾸면 특히 각도 구분이 어려웠다. 이 차이를 조사하기 위해 사용자 PC의 TITAN Xp에서 CNN을 학습하고, 같은 PC에서 특징·정규화·전통 머신러닝 구조와 GPU XGBoost를 비교했다.

분석은 “같은 손동작이라도 팔꿈치 각도에 따라 이두근과 삼두근이 서로 다르게 반응할 수 있는가?”라는 질문에서 출발했다. 아래에는 실제 채널 관찰, 구간 선정, 누출을 방지하는 분할, 성공·실패한 비교, 후보 선택과 현재 한계를 순서대로 정리한다.

| 평가 대상과 단계 | 핵심 결과 | 결과의 역할 |
|---|---|---|
| A의 기존 시험: 기록 13개·390시행 | 초기 1초 CNN 50.51%, 추가 선택 CNN 45.64% | 재사용 시험에서 추가 CNN의 개선 실패 |
| B의 기존 시험: 같은 기록의 마지막 6시행 | 200 ms CNN의 창 82.00%, 시행 다수결 97.14% | 관측 기록의 후속 시행 성능 |
| A 개발 전용 ML: 기록 51개·1,530시행 | 집계 SVM 21.24%, 독립 LDA 54.65±4.84% | 같은 기록 5폴드에서 후보 선택에 사용한 개발 성능 |
| ML 고정 23종: 외부 기록 5폴드·내부 3폴드 | 내부에서 1종을 고르는 절차 40.52±12.98% | 적응적으로 추가한 독립 LDA와 별도인 중첩 선택 절차 |
| XGBoost 24종: 같은 A 개발 자료 | 대표 52.24±9.03%, 중첩 선택 46.70±8.40% | 개발 대표와 24종 선택 절차를 구분한 후속 비교 |
| XGBoost 각도 학습량 후속 16종 | 개발 선택 52.88±6.99%, F1 0.5087 | 개발 전용 탐색; 새 외부 평가 없음 |
| 강의 기준 C: 동일 기록 내 무작위 시행 분할 | RF 시행 다수결 96.20±0.89% | 강의 조건을 명시한 별도 비교 |

독립 LDA는 손동작과 각도를 각각 선형판별분석(LDA)으로 학습하고 최종 8클래스로 결합하는 모델이다.

A·B·C는 서로 다른 평가 문제다. 특히 **LDA 54.65%는 개발 선택 결과이고, 중첩 40.52%는 고정 23종 선택 절차의 결과**다. C의 높은 수치를 A의 일반화 개선으로 옮겨 해석하지 않는다. 논문 전문의 정확한 조건은 아직 미확인으로, 논문 수준 달성이나 독립적인 새 기록·참가자 일반화를 확인한 결과는 아니다.

이 문서는 `research/generalization-v2` 브랜치에서 축적한 누적 보고서다. 초기 공개 결과는 커밋 `264f38a38246308235b30fbe77a0be7bb21f54cd`에 보존했다. 초기 결과는 1–8절, 추가 CNN은 9절, 전통 ML 탐색은 10절, 강의 기준 C는 11절에서 확인할 수 있다.

## 1. 데이터와 분류 대상

| 기록 | 사람별 8개 조건, 총 64개 CSV |
| 반복 | 기록당 30개 시행, 총 1,920개 시행 |

| 클래스 ID | 손동작 | 팔꿈치 각도 |
|---:|---|---:|

| 1 | 주먹쥐기(fist) | 60° |

| 3 | 손펴기(open) | 60° |

여기서 <strong>기록(recording)</strong>은 한 참가자가 하나의 동작·각도 조건을 반복한 CSV 파일이고, <strong>시행(trial)</strong>은 그 기록 안에서 수행한 한 번의 반복이다. <strong>창(window)</strong>은 시행에서 추출한 200 ms 길이의 신호다. 파일명에 쓰인 `extor`는 원 제공자의 설명에 따라 회외로 해석했다.

클래스 번호는 현재 코드의 동작 우선 순서다. 이전 1주차 설계안과 강의의 혼동행렬은 각도 우선 순서를 사용하므로, 자료를 대조할 때에는 숫자 ID가 아니라 동작·각도 이름을 기준으로 연결한다. 최종 강의본 21쪽의 각도판 사진과 설명에 따르면, 참가자는 앉아서 테이블 위에 팔을 놓고 판의 30° 또는 60° 기준선에 맞춘 정적 자세를 유지했다. 여기서는 이 두 측정 조건을 파일 라벨로 사용한다. 사진에는 두 경사 기준선이 보이지만 해부학적 각도의 영점과 기준축을 정량 정의한 도식은 제시돼 있지 않다. 분류 대상은 이 두 자세 조건이다.

두 분류 요인을 하나의 8클래스로 묶으면 손동작·각도 조합을 한 번에 출력할 수 있다. 손동작과 각도를 별도로 예측하면 요인별 오류를 구분하기 쉽지만, 두 예측의 일관성을 별도로 평가해야 한다. 각도를 3종 또는 4종으로 늘리면 조합은 12개 또는 16개가 되어 조건별 데이터 확보와 인접 각도 구분이 추가 과제가 된다. 최종 평가의 출력은 8클래스를 유지했다. 추가 ML에서는 손동작과 각도를 따로 학습한 뒤 조합하는 구조도 비교했다(10절).

채널과 근육의 대응은 최종 강의본 20쪽의 전극 사진·표와 고정 커밋의 [데이터 README](https://github.com/TestUser-alt-dev/sEMG-Hand-Gesture-Elbow-Angle-Dataset/blob/cb64ded658b83ae97e6388dd373efad0e97bc47c/README.md)에 따른다.

| 채널 | 데이터 설명의 근육명 | 한국어 명칭 |
|---|---|---|
| CH1 | Extensor carpi radialis | 요측수근신근 |
| CH2 | Extensor digitorum | 총지신근 |
| CH3 | Flexor digitorum superficialis | 천지굴근 |
| CH4 | Biceps brachii | 상완이두근 |
| CH5 | Triceps brachii | 상완삼두근 |

파일명, 마커, 라벨과 채널 수는 원자료에서 검사했고, 파일별 해시는 [manifest](reference/corrected_v3/preprocessing/manifest.json)에 보존했다. 근육명은 제공된 측정 설명에 근거한다. 강의 사진에는 CH1·CH2가 전완 후면, CH3가 전완 전면, CH4가 상완 전면, CH5가 상완 후면에 배치돼 있다. 이 사진은 측정 배치의 설명 자료이며, 64개 기록 각각의 전극 상태와 동작 시점을 확인할 동기 영상은 없다.

관련 논문의 공개 초록은 랜덤 포레스트(random forest, RF)의 5폴드 평균 정확도를 <strong>96.72±0.58%</strong>로 보고했다. 최종 강의본 24·35쪽은 논문의 평가를 시행 단위 무작위 분할로 설명한다. 본문에서 논문의 상세 방법을 언급하는 부분은 이 강의 설명에 근거하며, 구독 제한으로 미확보인 논문 전문을 직접 확인한 범위와는 구분한다. A/B 실험은 입력 구간과 분할이 달랐다. 강의 조건을 별도로 구현한 C도 상세 논문 조건을 확인하기 전의 비교로 구분한다(11절).

## 2. 신호 전처리와 입력 구간

```mermaid
flowchart LR
    A[고정 커밋의 64개 CSV] --> B[파일 해시와 마커·라벨 검사]
    B --> C[시행별 에너지 최대 1초 선택]
    C --> D[200 ms 창 9개]
    C --> E[1초 시행 입력]
    D --> F[CPU 특징 분류기 / CNN]
    E --> G[시간 CNN / 집계 SVM]
    F --> H[A·B 개발 데이터의 5폴드 검증]
    G --> H
    H --> I[모델·학습 횟수·난수 시드 고정]
    I --> J[고정된 재사용 시험 데이터 평가]
    J --> K[초기 결과·오류 분석]
    K --> L[A 개발 전용 추가 탐색]
    L --> M[특징·구조 대조 및 중첩 검증]
```

위 흐름도는 에너지 기준 입력을 사용하는 A/B와 추가 개발 탐색의 관계를 보여준다. C는 1.5–3.5초의 고정 구간을 사용하는 별도 강의 조건으로 11절에 정의한다.

원 제공자는 신호에 60 Hz 노치 필터와 20–450 Hz 대역 통과 필터를 적용했다고 설명한다. 이번 실험은 제공된 필터링 신호를 그대로 사용했다.

데이터 설명의 명목상 시행 구성은 휴식 2초, 동작 1초, 휴식 2초다. 그러나 마커와 실제 동작의 시간 관계는 확인되지 않았다. A 개발 시행 1,530개 중 1,279개(83.59%)에서 마커 뒤 1–2초의 합산 에너지가 가장 컸다. 이에 따라 기존 CPU 실험과 같은 **신호 에너지 기준의 1초 구간 선택**을 적용했다.

1. 현재 마커부터 다음 마커 직전까지를 한 시행으로 구분한다.
2. 마커 뒤 0.5–3.5초를 시작점으로, 0.1초 간격의 1초 후보 구간을 만든다.
3. 5채널의 신호 제곱합이 가장 큰 구간을 선택한다. 에너지가 같으면 앞선 구간을 선택한다.
4. 선택한 1초 전체를 입력하거나, 200샘플 창을 100샘플씩 이동시켜 9개의 창을 만든다.

구간 선택은 해당 시행의 신호만 사용한다. 라벨, 다른 시행의 통계와 시험 점수는 사용하지 않는다. 다만 약 5초의 시행과 그 경계를 먼저 확보해야 하므로, 전체 처리 지연은 창 길이인 200 ms보다 길다. 에너지 합산에는 큰 진폭의 채널이 더 많이 기여한다. A 개발 시행의 3.92%에서는 한 채널이 선택 구간 에너지의 80%를 넘었다.

64개 원자료의 해시와 기존 창 시작점·정답이 모두 일치했다. 기존 특징의 앞 25열을 다시 계산한 최대 절대 오차는 **0.0**이었다. 검사 항목과 결과는 [데이터 검사 기록](reports/data/audit.json)에 있다.

### 강의 실습과 이번 실험의 관계

1주차 18쪽, 2주차 19쪽, 3주차 19쪽과 최종 강의본 57쪽의 본문·코드·그림을 대조했다. 2주차 자료는 2초 분석 구간에서 200 ms 창을 100 ms씩 이동해 19개의 창을 만드는 실습을 설명한다. 10쪽의 시작점 1.5초는 실습 가정으로 제시돼 있으며, 데이터의 동작 위치를 확인해 조정하도록 안내한다.

| 항목 | 강의의 기본 조건 | 이번 실험과 선택 이유 |
|---|---|---|
| 필터 | 60 Hz 노치, 20–450 Hz 4차 Butterworth; 예제는 Q=30과 `filtfilt` 사용 | 제공 신호에 이미 해당 대역의 필터가 적용돼 있어 추가 필터링 없이 사용 |
| 분석 구간 | 2초, 예제 시작점 1.5초 | A/B와 주요 ML 비교는 에너지 기준 1초; C는 예제의 2초 고정 구간 |
| 창 | 200 ms, 100 ms 간격, 19개 | 1초 입력은 9개, C의 2초 입력은 19개 |
| 기본 특징 | RMS·MAV·WL·ZC·SSC × 5채널 = 25개 | 같은 순서와 계산식 유지; ZC 임계값 0.01, SSC는 기울기 부호 변화 횟수 |
| 확장 입력 | 25개 시간영역 특징 | 일부 CPU 비교에 70개 특징을, CNN에는 원파형 또는 STFT를 사용 |
| 분할 | 같은 시행의 겹치는 창을 분리하지 않음 | 실제 파일당 30개 시행을 식별하고 A는 기록, B는 시행 단위로 분리 |
| 표준화 | 학습 자료에서만 통계 계산 | 각 CV 학습 폴드에서 계산하고 검증·시험에는 적용만 수행 |
| 평가 목적 | 시행 단위 무작위 분할, 80/20 및 5폴드 | A는 기록 이동, B는 후속 시행, C는 같은 기록의 무작위 시행을 평가 |
| 모델 설정 | SVM C=1, RF 100트리, XGBoost 400트리·깊이6·학습률0.05 | 기존 CPU 검증에서 고른 설정을 보존하고, CNN 후보는 별도 사전 계획에 따라 선택 |

강의 예제 13쪽의 파일 단위 분할은 한 파일을 하나의 시행처럼 다룬다. 실제 제공 파일에는 30개 마커가 있으므로, 이번 구현에서는 파일과 시행을 구분해 그룹을 보존했다. 특징을 먼저 캐시하더라도 각 특징이 해당 창 안에서만 계산되고, 그룹 분할과 학습 통계 계산을 독립적으로 관리하면 겹치는 창의 분할 간 혼입을 검사할 수 있다.

200 ms 창과 50% 겹침은 강의의 특징 추출 조건을 유지한 선택이다. 100 ms마다 새 창을 얻어 인접 시간 변화를 살피되, 겹친 표본을 독립 시행으로 취급하지 않도록 같은 시행을 묶었다. 최종 강의본 11·54쪽은 1D CNN과 주파수 특징을 확장 비교로 제안한다. 초기 실험은 그 확장 방향에서 시간 구조의 효과와 기록 간 성능 차이를 검토했고, 추가 ML에서는 시행 요약과 분류 구조를 비교했다.

강의가 설명하는 논문 방법에서도 2초 구간의 정확한 시작점, 창을 모델의 표본으로 구성하는 세부 방식, 표준화의 적용 순서는 불명확한 항목으로 남아 있다(최종 강의본 23–30·53쪽). 이 저장소에서는 구간 선택, 창 다수결, 학습 폴드별 정규화를 별도 구현 조건으로 명시했다.

1주차의 클래스·채널 설계와 각도별 관찰은 1·4절, 2주차의 특징·그룹 분할은 이 절과 3절, 3주차의 모델·지표·혼동행렬·한계는 5–9절에 대응한다. 이 저장소는 이 확장 실험의 보고서다. 강의가 별도로 요구한 노트북 또는 PDF, `dataset.npz`, 필터 전후 스펙트럼과 같은 제출 묶음의 완성 여부는 별도이며, 이미 필터링된 제공 신호로 필터 적용 전 원신호를 복원할 수는 없다.

## 3. 평가 분할과 지표

| 구분 | A: 미관측 기록 | B: 관측 기록의 후속 시행 |
|---|---|---|
| 개발/시험 | 기존 51/13개 기록 | 각 기록의 1–24/25–30번째 시행 |
| 개발/시험 시행 수 | 1,530/390 | 1,536/384 |
| 개발/시험 200 ms 창 수 | 13,770/3,510 | 13,824/3,456 |
| 검증 | 개발 기록을 클래스별 5폴드 | 첫 24시행을 연속 5블록으로 분리 |
| 같은 기록이 양쪽에 존재 | 없음 | 있음 |
| 참가자 자체의 분리 | 아님 | 아님 |

A의 시험 13개 기록은 6명의 참가자에게서 나왔다. 개발 데이터와 시험 데이터에 같은 참가자가 포함될 수 있으므로, A가 측정하는 대상은 **참가자가 겹칠 수 있는 미관측 기록의 분류 성능**이다. B는 각 기록의 첫 24개 시행으로 개발한 모델을 같은 기록의 마지막 6개 시행에 적용한다. B의 개발 교차검증에는 앞뒤 블록이 서로 학습·검증 자료가 되는 조합이 있으며, 최종 시험만 시간상 후속 시행으로 구성된다.

기존 `split.npz`의 인덱스를 그대로 사용했다. 같은 시행에서 나온 겹치는 창은 모두 같은 분할과 폴드에 배정했으며, 서로 다른 시행에서 추출한 원신호 구간의 중복도 검사했다. 입력 정규화 통계는 각 학습 폴드에서만 계산했다. 참가자 ID와 기록 ID는 모델 입력에 포함하지 않았다.

**창 정확도**는 200 ms 창의 정답 비율이다. **시행 정확도**는 시행별 정답 비율이며, 200 ms 모델은 한 시행의 9개 창 예측을 다수결로 합친다. 동률이면 가장 작은 클래스 ID를 선택한다. 1초 모델은 시행당 하나의 예측을 직접 출력한다. **정밀도**는 특정 클래스로 예측한 표본 중 실제 그 클래스인 비율이고, **재현율**은 해당 클래스의 실제 표본 중 맞힌 비율이다. **macro-F1**은 클래스별 정밀도와 재현율로 계산한 F1의 단순 평균으로, 각 클래스에 같은 가중치를 둔다. 정밀도와 재현율도 클래스별 값을 단순 평균해 macro 값으로 제시한다. 예측이 없는 클래스의 정밀도는 0으로 처리한다. 두 정확도의 차이는 %p(퍼센트포인트)로 표시한다.

두 시험 데이터는 이전 실험에서도 사용된 **회고적 재사용 시험 자료**다. 이번 실험의 모델 선택에는 개발 교차검증만 사용했지만, 시험 자료 자체가 처음 공개되는 독립 평가 조건은 아니다. 또한 제공자의 필터 적용 범위와 경계 처리가 상세히 알려지지 않아, 원자료 생성 단계의 시행 간 필터 영향은 이번 구간 중복 검사로 판단할 수 없다.

### 추가 실험의 분할과 시험 노출 이력

| 단계 | 학습·선택 자료 | 평가 자료와 사용 범위 |
|---|---|---|
| 추가 CNN | A 개발 51기록, 같은 기록 5폴드 | 고정 16종 중첩 검증과 한 번의 기존 A 시험 비교; B는 미사용 |
| 전통 ML 79종 | A 개발 51기록만 캐시, 시행당 하나의 특징벡터 | 같은 기록 5폴드로 후보 선택; 기존 A/B 시험 미사용 |

A 개발의 한 기록은 참가자·클래스 하나의 30시행이다. 기록을 제외하면 그 참가자의 해당 클래스 예시가 모두 빠지고, 다른 클래스 기록은 학습에 남을 수 있다. 각 폴드의 클래스별 학습 기록은 4–6개였다. 따라서 반복 시행 수와 독립적인 측정 조건의 수를 구분해야 한다.

추가 ML의 대표 선택과 모든 학습 통계는 개발 자료 안에서 정했다. 중첩 구성과 참가자 제외 진단도 과거에 이 자료의 결과를 본 이력은 공유한다. 현재 데이터에는 새로운 독립 시험 세션이 없다.

## 4. 이두근·삼두근 반응에 대한 가설과 관찰

### 4.1 질문을 관찰 가능한 비교로 정의

분석을 시작할 때 세운 가설은 **같은 손동작에서도 각도에 따라 이두근과 삼두근의 반응 방향이 다를 수 있다**는 것이다. 이를 신호에서 확인하기 위해, 같은 참가자·같은 손동작의 30°와 60° 기록에서 CH4와 CH5의 진폭 변화 방향을 비교했다.

진폭 요약에는 제곱평균제곱근(root mean square, RMS)을 사용했다. 채널의 신호 표본을 $x_n$이라고 할 때, 선택한 1초 구간의 RMS는 다음과 같다.

$$
\mathrm{RMS}=\sqrt{\frac{1}{N}\sum_{n=1}^{N}x_n^2},\qquad N=1000.
$$

각 기록의 30개 시행에서 RMS를 구한 뒤 중앙값을 계산했다. 아래 변화율은 **60° 기록의 중앙값을 30° 기록의 중앙값으로 나눈 비율에서 1을 뺀 값**이다. 따라서 서로 다른 두 기록의 대표값을 비교하며, 30°의 특정 시행과 60°의 특정 시행을 일대일로 대응시킨 통계는 아니다.

분석 범위는 두 각도 기록이 모두 A 개발 데이터에 포함된 21개 참가자·동작 쌍, 총 42개 기록으로 제한했다. 8명의 참가자가 여러 동작에 반복 포함되며, 21쌍을 독립된 21명으로 볼 수는 없다. 이 절은 문서 보완을 위한 기술통계 분석이며, 분류 모델의 입력·선택·시험 결과에는 반영하지 않았다.

### 4.2 실제 신호와 RMS 결과

21쌍 중 **CH4 증가·CH5 감소는 4쌍**, 두 채널 모두 증가는 16쌍, CH4 감소·CH5 증가는 1쌍이었다. 증가와 감소는 비율이 1보다 큰지 작은지로 구분했다. 통계적 유의성 검정은 수행하지 않았다.

참가자 a의 손펴기 원파형을 확인하고 30개 시행의 RMS 시간 변화를 함께 비교했다. CH4에서는 마커 뒤 약 1–2.5초에 두 각도 모두 진폭이 커졌고, 60°의 증가가 더 컸다. CH5의 60° RMS는 30°보다 낮은 구간이 많았으며, 이 차이는 CH4의 진폭 증가가 두드러진 구간 밖에서도 관찰됐다.

이전 1주차 최종 보고서의 같은 손펴기 사례는 마커 뒤 **5초 전체**를 요약해 CH4 비율 1.504, CH5 비율 0.704를 보고했다. 원자료를 같은 방식으로 재계산한 값도 소수점 셋째 자리에서 일치했다. 이번 표의 +37.0%, −20.8%는 **에너지로 선택한 1초**의 결과다. 같은 기록이라도 요약 구간에 따라 크기가 달라지므로, 이전 관찰과 현재 입력 구간의 수치를 구분한다.

이 결과는 두 채널이 항상 같은 방향으로 변하는 것은 아니라는 관찰을 뒷받침한다. 동시에 두 채널이 함께 증가한 16쌍은 ‘각도가 커지면 CH4는 증가하고 CH5는 감소한다’는 규칙이 전체 자료에 적용되지 않음을 보여준다. 특히 g의 회내에서 CH4 변화는 +1.0%로 작아, 방향 구분만으로 큰 반응을 의미하지 않는다.

### 4.3 생리적 해석의 범위

CH4와 CH5의 대응 근육은 데이터 설명으로 확인했지만, RMS는 기록된 전기 신호의 크기다. sEMG 진폭에는 신경 구동뿐 아니라 운동단위 활동전위의 형태와 측정 조건도 영향을 준다([Farina 등, 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4254845/)). 이번 자료에는 근력, 실제 관절 운동 및 전극 상태를 함께 확인할 측정값이 없다.

따라서 확인된 결과는 **일부 참가자·동작 쌍에서 이두근 채널의 RMS가 증가하고 삼두근 채널의 RMS가 감소했다**는 것이다. 삼두근의 실제 이완 여부와 각도가 변화의 직접 원인인지는 추가 측정이 필요하다. 30°와 60°가 별도 기록이므로 각도 차이와 기록 조건의 차이도 함께 고려해야 한다.

## 5. 초기 모델과 선택 절차

### 5.1 후보 모델

CPU 기준선은 서포트 벡터 머신(support vector machine, SVM), RF, XGBoost다. SVM은 클래스 사이의 경계를 학습하며 RBF 커널로 비선형 관계를 표현한다. RF는 서로 다르게 학습한 결정 트리의 예측을 결합하고, XGBoost는 앞선 모델의 오차를 줄이는 방향으로 트리를 순차 추가한다. A의 기존 기준선은 25개 특징, B의 SVM·XGBoost는 70개 특징을 사용했다. 기존 SVM은 RBF 커널·C=10과 로그 특징 변환, RF는 300트리·말단 노드 최소 표본 수 3을 사용했다. XGBoost는 300트리·학습률 0.05이며 선택 깊이는 A 3, B 6이었다. 이 설정들은 강의의 기본값과 구분되는 기존 CV 선택 결과다. B의 RF는 고정 1–2초 구간을 사용하므로, 아래 비교에서 입력 차이를 함께 표시한다.

CNN은 원파형 또는 시간별 주파수 정보를 입력으로 사용한다. 합성곱 필터가 인접 시점의 패턴을 학습하고, 뒤의 층이 채널과 시간 정보를 결합해 8개 클래스의 점수를 출력한다. 단시간 푸리에 변환(short-time Fourier transform, STFT)은 짧은 신호 구간의 주파수 성분을 시간 순서대로 배열한 표현이다.

| 계열 | 입력·구조 | 파라미터 |
|---|---|---:|
| 원파형 CNN | 5채널 → 채널별 Conv1d(15,stride2) → 채널 혼합 Conv(9,stride2) → Conv(5) → 평균/최대 pooling + log-RMS → MLP | 53,720 |
| 주파수 CNN | 64샘플 Hann STFT, hop16 → 5×33=165채널 → Conv1d(1,3,3), 각 64채널 → 평균/최대 pooling → MLP | 44,488 |
| 상대 주파수 CNN | 표본 전체 log-power 평균을 제거한 뒤 동일 CNN | 44,488 |
| 증강 주파수 CNN | 학습 때 공통/채널별 log-gain 증강 후 동일 CNN | 44,488 |
| 집계 SVM | 같은 1초 안 9개 창의 70특징을 평균 또는 평균+표준편차로 집계 | 해당 없음 |

200 ms 입력의 STFT는 9개 프레임, 1초 입력은 59개 프레임으로 구성된다. 패딩을 하지 않아 각 입력의 마지막 8샘플은 STFT에 포함되지 않는다. 1초 CNN은 시행 전체의 시간 순서를 이용하고, 집계 SVM은 같은 1초 안의 9개 창에서 얻은 특징을 평균 또는 평균·표준편차로 요약한다. 1초 모델의 평가 단위는 시행이므로 창 정확도는 정의하지 않는다.

상대 주파수 모델은 표본 전체의 log-power 평균 하나를 제거해 공통 진폭 수준을 줄인다. 증강 모델은 학습 시 공통 자연로그 이득의 표준편차를 0.30, 채널별 자연로그 이득의 표준편차를 0.15로 설정했다. 검증과 시험에는 이득 증강을 적용하지 않았다. 집계 SVM은 RBF 커널과 `gamma=scale`을 사용하고, 평균 벡터는 `C=0.1, 1, 10`, 평균·표준편차 벡터는 `C=1, 10`을 비교했다.

### 5.2 학습과 선택 기준

실제 데이터 학습 전에 [초기 계획](configs/PROTOCOL_GPU.md)을 기록했다. 첫 개발 교차검증에서 기록 간 성능 저하를 확인한 뒤, 시험 평가 전에 [보완 계획](configs/PROTOCOL_EXTENSION.md)을 추가했다. 이 두 파일은 당시의 계획과 해시를 보존한 원본이다. 실행 설정은 [기본 설정](configs/CONFIG_FROZEN.json), [보완 설정](configs/EXTENSION_FROZEN.json), [CPU 대조군 설정](configs/CPU_CONTEXT_CONFIG.json)에 있다.

CNN의 공통 설정은 AdamW, 학습률 0.001, 가중치 감쇠 0.001, 배치 크기 128, 드롭아웃 0.25, 라벨 스무딩 0.05, 기울기 노름 상한 5다. 한 번의 전체 학습 자료 순회를 epoch라고 한다. 교차검증 학습은 최소 8회, 최대 40회 수행하고, 검증 macro-F1이 8회 연속 개선되지 않으면 중단한다. 최적 체크포인트는 첫 epoch부터 기록하므로, 저장된 최적 시점은 최소 실행 횟수인 8보다 작을 수 있다.

모델 선택에는 **5폴드 교차검증(cross-validation, CV)의 평균 macro-F1**을 사용했다. A와 B 각각에서 200 ms 후보 1개와 1초 후보 1개를 선택했다. 200 ms는 창 macro-F1, 1초는 시행 macro-F1을 기준으로 삼았다. 최종 학습 횟수는 선택 모델의 5개 폴드에서 얻은 최적 epoch의 중앙값으로 고정했다.

최종 CNN은 사전에 지정한 난수 시드(seed) 42와 2026으로 각각 학습한 뒤 두 모델의 클래스 확률을 평균했다. 따라서 CV 표는 폴드마다 하나의 시드로 학습한 결과이고, 시험 표는 두 모델의 확률 평균 앙상블 결과다. 개별 시드의 점수도 결과 JSON에 보존했다.

CNN 8후보×2평가×5폴드의 80회 학습과 CPU 대조군 5후보×2평가×5폴드의 50회 학습을 수행했다. [최종 시험 전 선택 파일 해시](configs/FINAL_EVALUATION_GATE.json)를 저장한 뒤 시험을 평가했다. 개발 결과를 보고 후보를 확장했으므로 CV 점수에는 선택 편향이 포함될 수 있다. 이 초기 실행 묶음은 시험 평가 후 고정했다. 이후의 추가 실험은 9–11절의 별도 계획·코드·결과로 보존하며, 10절 ML 단계에서는 기존 시험을 다시 사용하지 않았다.

강의의 논문 결과를 비교 배경으로 볼 때에는 출처 내부의 차이도 남아 있다. 최종 강의본 38·45–47쪽은 논문 Table 2의 정확도와 Fig. 5 혼동행렬의 대각합에서 계산한 정확도가 일치하지 않음을 설명한다. 예를 들어 RF는 각각 96.88%와 371/384=96.61%다. 표와 그림의 차이가 발생한 이유는 현재 자료에서 확인되지 않았다. 또한 논문의 96.72±0.58%는 5폴드 평균이고, 이번 B의 97.14%는 시간순으로 남긴 시험 시행의 다수결 결과여서 평가 조건과 집계 방식이 다르다.

![선택 모델의 5폴드 학습 곡선](figures/learning_curves.png)

A의 학습 정확도는 90–100%까지 높아졌지만 검증 정확도는 낮은 수준에 머물렀다. 선택 모델의 폴드별 최적 시점을 집계한 최종 학습 횟수는 A에서 200 ms와 1초 모두 2 epoch, B에서 각각 25와 18 epoch였다. A의 조기 성능 저하와 B의 높은 성능을 함께 보면, 관측한 기록의 패턴을 학습하는 능력에 비해 기록을 바꿨을 때의 일반화가 제한됐다.

A 개발 데이터에서 기록 간 log-RMS 표준편차는 채널별 0.217–0.333, 기록 내 표준편차는 0.065–0.095였다. 기록 간 진폭 차이가 더 컸지만, 사람·동작·각도·측정 조건이 함께 달라져 각각의 영향을 분리할 수 없었다. 4절의 채널 관찰 역시 기록별 반응이 일정하지 않음을 보여준다. 이 두 관찰만으로 전극 상태나 라벨 오류를 성능 저하의 원인으로 특정할 수는 없다.

### 8.3 B의 각도 혼동과 차이의 불확실성

![B 시행 혼동행렬](figures/confusion_trial.png)

*그림 6. B 시험 시행의 혼동행렬. 왼쪽부터 기존 SVM 시행 다수결, 200 ms CNN 시행 다수결, 1초 CNN, 1초 집계 SVM이다. 행은 정답, 열은 예측이며 숫자와 색의 기준은 그림 5와 같다. 200 ms CNN에서 틀린 11개 시행은 모두 같은 손동작의 두 각도를 혼동한 사례다.*

## 9. 기록 일반화를 위한 추가 CNN 비교

### 9.1 관찰, 가설과 고정 조건

초기 A 실험에서는 학습 정확도가 높아져도 기록을 분리한 검증 점수가 낮았고, 같은 손동작의 두 각도를 자주 혼동했다. 이에 따라 입력 길이, 진폭 표현, 손동작·각도 보조 학습과 주파수 해상도를 비교했다. 기존 A 개발 51개 기록과 5폴드 배정을 유지하고, 후보 선택에는 시행 macro-F1 평균을 사용했다. 모든 비교는 사용자 PC에서 수행했다.

초기 16종은 CPU 9종과 CNN 7종으로 구성했다. 이후 개발 결과를 근거로 보조 손실·클래스 가중치, STFT 길이, 진폭 증강과 계층 구조를 대조하는 7종을 추가했다. 추가 후보는 각각 실행 전에 계획을 기록했으며, 고정 16종의 중첩 평가와 구분했다. 같은 1초 후보끼리 비교하고, 2초·5초 입력은 문맥 길이가 다른 후보로 표시했다.

| 문제 관찰 | 가설과 바꾼 조건 | 개발 시행 정확도 | 판단 |
|---|---|---:|---|
| 동작보다 각도 오류가 많음 | 기본 1초 CNN에 손동작·각도 보조 손실 추가 | 37.88% → 46.52% | 후속 비교 대상으로 유지 |
| 구간 위치와 길이가 불확실함 | 에너지 최대 2초 입력 / 전체 5초 RMS 포락선 | 37.05% / 29.24–32.48% | 길이 확대만으로 향상되지 않음 |
| 보조 손실과 가중치가 함께 변경됨 | 보조 손실 없이 클래스 가중치만 적용 | 38.21% | 보조 과제를 포함한 구성이 더 높았음 |
| STFT의 주파수 해상도 | 보조 모델의 창 길이를 64→128→256표본으로 변경 | 46.52% → 43.04% → 47.38% | 256표본을 후속 비교에 사용 |
| 채널 진폭의 기록 차이 | 256표본 보조 모델에 학습 시 진폭 증강 추가 | 47.38% → 48.85% | 개발 macro-F1로 대표 선택 |
| 각도 경계가 손동작마다 다를 수 있음 | 동작별 각도 계층 구조 / RMS 보조 입력 | 44.28% / 45.07% | 대표 모델보다 낮음 |
| 단일 후보의 변동 | 개발 상위 두 모델의 확률 평균 | 47.50% | F1 0.4216으로 대표의 0.4328보다 낮아 미채택 |

첫 보조 모델에서는 손실·가중치·학습 상한이 함께 바뀌었다. 따라서 46.52%를 보조 손실 하나의 효과로 해석하지 않고, 같은 추가 학습 조건의 가중치 대조군 38.21%와 함께 판단했다. 세부 설정과 23개 후보의 전체 수치는 [추가 CNN 보고서](experiments/generalization_v2/README.md)에 보존했다.

대표 모델은 STFT 256표본·간격 32표본, 합성곱 3층, 손동작·각도 보조 출력과 학습 시 진폭 증강을 사용했다. 파라미터는 75,982개이며, 보조 교차엔트로피 가중치는 각각 0.3이다. 새 후보의 학습 상한은 60 epoch, 최소 실행은 12 epoch, 조기종료 대기는 12 epoch였다. AdamW, 배치 크기와 기본 규제는 5절의 설정을 유지했다. 진폭 증강의 공통·채널별 자연로그 이득은 각각 [−0.15, 0.15]에서 뽑았다.

그림 7은 개발 대표 선택 전후의 학습 곡선을 비교한다.

*그림 7. A 개발 기록의 같은 5폴드에서 비교한 기존 CNN과 선택 CNN의 학습 곡선. 점선은 macro-F1로 선택한 epoch다. 학습 정확도 상승에 비해 기록 분리 검증 정확도가 낮은 현상이 추가 모델에서도 남았다. 두 모델은 목적함수가 달라 손실값의 크기를 직접 비교하지 않는다.*

### 9.2 중첩 선택과 재사용 시험에서의 실패

고정 16종의 중첩 교차검증은 외부 기록 5폴드 각각에서 내부 기록 3폴드로 후보와 epoch를 선택했다. 다섯 선택을 모두 고정한 뒤 외부 결과를 계산했다. 이 절차의 정확도는 27.44±12.15%로, 같은 외부 폴드의 기존 CNN 30.14±11.29%보다 낮았다. 이 수치는 적응적으로 추가한 7종이나 최종 대표 CNN의 중첩 점수가 아니다.

추가 CNN의 개발 대표를 확정한 뒤, 기존 A 시험 390시행에서 한 번의 고정 비교를 수행했다. 각 신경망은 시드 42와 2026으로 학습하고 두 확률을 평균했다. 이 시험은 이미 여러 번 사용된 자료이며, 새로운 독립 시험으로 간주하지 않았다.

## 10. 전통 머신러닝의 특징·구조 탐색

### 10.1 각도 오류를 바탕으로 세운 비교 가설

추가 CNN에서도 각도 오류가 남았고, 모델을 더 복잡하게 만드는 것만으로 기록 이동의 성능 저하를 줄이지 못했다. 전통 ML에서는 시행을 요약하는 특징과 분류 구조를 함께 검토했다. 반복 시행의 수에 비해 독립적인 측정 기록이 적다는 점을 고려해, 기록별 통계에 과적합하는 복잡한 경계를 줄이는 후보도 포함했다.

| 관찰 | 검토한 가설 | 비교한 방법 |
|---|---|---|
| 같은 기록 안의 진폭도 시간에 따라 변함 | 평균·표준편차가 놓친 분포 정보가 있음 | 중앙값·사분위 범위(IQR) 추가 |
| 채널별 단일 특징만으로 각도 구분이 어려움 | 채널 관계와 주파수 분포가 보완 정보를 제공함 | 대역전력, 공분산 행렬 로그, 상관, coherence |
| 학습 정확도와 기록 분리 검증의 차이가 큼 | 불필요한 특징과 복잡한 경계가 과적합을 키움 | 특징 선택, PCA, SVM 규제, 트리 말단 크기, LDA |
| 같은 손동작의 두 각도를 자주 혼동함 | 각도 학습에 여러 손동작의 표본을 모으면 도움이 됨 | 8클래스 직접 분류 / 독립 분류 / 계층 분류 |
| CH4·CH5의 변화 방향이 사람·동작별로 다름 | 상완 채널의 크기 또는 비율에 유용한 각도 정보가 있음 | 상완·전완 채널 선택, 각도 입력 제한, 표본 내 진폭 기준 |

이두근·삼두근의 반응이 다를 수 있다는 질문은 4절의 실제 채널 관찰과 연결했다. 다만 이 분류 실험은 근력이나 근육 이완의 인과 검정이 아니다. 채널 선택이 예측에 주는 영향을 측정한다.

### 10.2 입력, 모델과 선택 규칙

입력 캐시는 A 개발 51개 기록의 1,530개 시행만 포함했다. 기존 A/B 시험 행은 넣지 않았다. 초기 57종을 비교한 뒤 독립 구조의 이득을 요인별로 확인하는 22종을 추가했다. 총 79종 중 77종은 같은 에너지 기준 1초만 사용했고, 2종은 같은 시행의 5초에서 낮은 진폭 기준을 추가했다. 그 기준은 100 ms log-RMS 50개의 20백분위수이며, 생리적 휴식으로 확인된 구간은 아니다.

| 특징군 | 차원 | 구성 |
|---|---:|---|
| 기존 창 특징 요약(`legacy`) | 140 | 70특징 × 9창의 평균·표준편차 |
| 분포 요약(`robust`) | 280 | 같은 특징에 중앙값·IQR 추가 |
| 주파수(`spectrum`) | 105 | Welch 상대·절대 대역전력, 평균·중앙 주파수, 엔트로피·평탄도, RMS |
| 채널 관계(`relations`) | 150 | 공분산 행렬 로그, 파형·포락선 상관, 상대 RMS·비율, coherence |
| 결합(`fusion`) | 395 | 기존 요약·주파수·채널 관계 결합 |
| 상대량(`relative`) | 320 | 일부 절대 진폭 특징 제거, 상대 전력과 trace 정규화 공분산 |
| 상완 / 전완 | 56 / 84 | 기존 요약 중 CH4·5 / CH1–3만 사용 |

Welch와 coherence에는 길이 256표본의 Hann 창과 128표본 간격을 사용했다. coherence는 교차 스펙트럼의 크기 제곱을 두 신호의 전력 스펙트럼 곱으로 나눈 값이다. 공분산 특징은 전체 파형과 네 대역의 FFT 투영 파형에서 계산하고, 표본공분산 95%와 평균 분산을 대각 원소로 갖는 단위행렬 5%를 혼합한 뒤 행렬 로그를 벡터화했다. 이런 시행 내부 특징은 미리 계산했지만, 표준화·PCA·특징 선택은 학습 폴드 안에서만 수행했다.

모델은 SVM, RF, ExtraTrees, Histogram Gradient Boosting과 선형판별분석(linear discriminant analysis, LDA)을 비교했다. ExtraTrees는 무작위 후보 분할을 사용하는 트리 앙상블이다. LDA는 클래스별 평균과 공통 공분산으로 경계를 계산하며, 이번에는 공분산 추정의 변동을 줄이는 `shrinkage=auto`를 적용했다. 정확한 설정은 다음과 같다.

| 모델·변환 | 사전에 고정한 비교 범위 |
|---|---|
| SVM | RBF, C=0.1/1/10, `gamma=scale`, `probability=False` |
| RF / ExtraTrees | 300트리, 최대 특징 비율 0.5, 말단 최소 표본 1/3/6개, 시드 42 |
| Histogram GB | 100회, 학습률 0.05, L2=1, 최대 말단 7/31개, 내부 무작위 조기종료 해제 |
| LDA | `solver=lsqr`, `shrinkage=auto` |
| 정규화 | StandardScaler / RobustScaler, 각 학습 폴드에서 계산 |
| 특징 축소 | 누적 설명 분산 95%의 PCA / F통계 상위 32·64개 |

F통계는 학습 기록별 특징 중앙값에서 계산했다. 같은 기록의 30시행을 독립 기록 30개처럼 특징 선택에 세지 않기 위한 구성이다. 선택 기준은 동일한 개발 기록 5폴드의 **8클래스 macro-F1 평균**이며, 동률은 후보 이름순으로 정했다.

독립 구조는 손동작 4종과 각도 2종을 각각 학습한 뒤 최종 8클래스로 결합한다. 계층 구조는 손동작별 각도 분류기를 두고, 예측한 동작 확률과 조건부 각도 확률을 곱한다. 추론에는 실제 손동작 정답을 주지 않았다. SVM의 저장용 점수 변환은 보정된 확률이 아니므로 확률 앙상블에서 제외했다.

### 10.4 고정 23종의 중첩 선택 절차

개발 최고값에 대한 의존성을 줄이기 위해, 초기 계획에 지정한 23종을 외부 기록 5폴드·내부 기록 3폴드로 평가했다. 각 외부 폴드에서 내부 macro-F1이 가장 높은 후보를 선택하고, 모든 선택을 잠근 뒤 외부 점수를 계산했다. 확률 앙상블은 내부 점수 상위 두 확률 모델을 같은 가중치로 평균했다.

### 10.5 기록 구성과 참가자 변화에 대한 진단

개발 대표를 고정한 뒤 기록 분할의 난수 시드 두 개와 참가자 제외 진단을 추가했다. 진단 결과를 보고 대표 모델이나 파라미터를 다시 고르지 않았다. 참가자 제외 진단에서는 매번 한 사람의 개발 기록 전체를 학습에서 뺐다. 다만 후보 설계·선택에는 같은 참가자들의 이전 개발 결과를 사용했다.

| 고정 모델 | 기록 분할 1 | 기록 분할 2 | 참가자 제외 평균±SD |
|---|---:|---:|---:|
| 기존 집계 SVM | 18.62% | 23.25% | 48.86±9.59% |
| 독립 ExtraTrees | 40.09% | 41.78% | 56.94±17.42% |
| 개발 대표 독립 LDA | 49.53% | 53.41% | 55.25±20.09% |
| 5초 기준 혼합 모델 | 44.19% | 44.19% | 50.83±8.23% |

기록 분할 1·2는 각각 시드 20261022·20261023의 5폴드 정확도 평균이다. 참가자 제외 평균은 8명에 같은 가중치를 준 값이다. 개발에 남은 기록 수와 클래스가 사람마다 달라, 참가자별 지표와 1,530개 예측을 합친 macro-F1을 별도로 보존했다.

그림 12에서는 평균 정확도에 가려진 참가자별 차이를 확인할 수 있다.

![참가자 제외 진단](experiments/ml_v3/artifacts/figures/held_person_diagnostic.png)

*그림 12. 학습에서 제외한 참가자별 개발 시행 정확도. 각 학습은 해당 사람을 제외했지만, 후보 설계와 선택에는 이 참가자들의 개발 자료를 사용한 이력이 있다. 따라서 이 그림은 선택 후 참가자 변화에 대한 민감도 진단이며, 독립적인 신규 참가자 시험의 확정값은 아니다.*

독립 LDA는 다른 두 기록 분할에서도 기존 SVM보다 높았지만, 참가자별 변동은 컸다. 참가자 제외 진단에서 ExtraTrees의 평균이 더 높아도 개발 대표를 바꾸지 않았다. 새로운 세션 자료에서 각도·전극 위치·시행 시점을 함께 확인해야 기록 조건과 각도 정보의 영향을 더 구체적으로 분리할 수 있다.

### 10.6 XGBoost: 부스팅과 분류 구조의 추가 대조

앞선 ML에서는 독립 LDA가 직접 분류보다 높았지만, 학습 정확도와 개발 정확도의 차이가 컸다. 다음 가설은 비선형 경계를 학습하는 부스팅에 독립 구조를 적용하면 각도 구분이 더 나아지는지였다. 사용자 PC의 별도 가상환경에 XGBoost 3.0.5를 설치하고 TITAN Xp에서 실행했다.

기존·분포 요약·결합·상대량 특징 4종, 직접·독립 구조 2종, 트리 깊이 2·4·6을 교차한 24종을 실행 전에 고정했다. 나머지는 200라운드, 학습률 0.05, 최소 자식 가중치 5, L2 정규화 5, 행·열 표본 비율 각 0.8, histogram bin 128로 통일했다. 독립 구조는 손동작과 각도의 분류 확률을 곱해 8클래스 확률로 결합한다. 클래스 균형 가중치는 각 학습 헤드의 라벨 빈도에서만 계산했으며, 트리 입력에 별도 표준화나 특징 선택은 적용하지 않았다.

기존 A 개발 51기록·1,530시행과 동일 기록 5폴드를 사용했다. 대표 선택 기준은 8클래스 macro-F1의 폴드 평균이었다. 24종 전체에 대해 외부 5폴드·내부 3폴드를 구성하고, 내부 선택을 잠근 뒤 외부 점수를 계산했다. 표의 깊이 2 대조는 특징과 구조를 비교하며, 그림 13은 깊이까지 바꾼 전체 요인을 보여준다.

| 특징 | 구조 | 깊이 2의 개발 시행 정확도 평균±SD | macro-F1 | 각도 정확도 |
|---|---|---:|---:|---:|
| 기존 요약 | 직접 | 24.52±4.67% | 0.2202 | 35.03% |
| 기존 요약 | 독립 | 49.10±7.12% | 0.4660 | 60.50% |
| 분포 요약 | 직접 | 24.43±2.29% | 0.2171 | 34.27% |
| 분포 요약 | 독립 | 49.54±9.43% | 0.4673 | 60.12% |
| 결합 | 직접 | 26.84±7.14% | 0.2567 | 33.49% |
| 결합 | 독립 | 52.24±9.03% | 0.5050 | 60.62% |
| 상대량 | 직접 | 20.04±5.72% | 0.1830 | 27.61% |
| 상대량 | 독립 | 42.44±9.53% | 0.4065 | 48.08% |

![XGBoost 특징 구조 깊이 비교](experiments/xgb_v4/artifacts/figures/factor_comparison.png)

*그림 13. 같은 개발 기록 5폴드에서 특징 4종·분류 구조 2종·깊이 3종을 비교한 결과. 점은 시행 정확도 평균, 오차 막대는 폴드 간 표준편차다. 폴드의 학습 자료가 중첩되므로 이 막대는 독립 표본의 신뢰구간이 아니다.*

XGBoost 대표는 `fusion_independent_d2`였다. 개발 정확도는 **52.24±9.03%**, macro-F1은 **0.5050**였다. 손동작 정확도는 89.10%, 각도 정확도는 60.62%였고, 학습 정확도는 98.37%였다. 같은 개발 분할의 독립 LDA 54.65%, F1 0.5138보다 낮아 기존 개발 대표를 교체하지 않았다.

그림 14는 선택한 XGBoost의 학습 진행을 보여준다. 200라운드는 실행 전에 고정했으며 곡선으로 중단 시점이나 후보를 다시 정하지 않았다. 학습 손실은 클래스 가중치가 적용되고 검증 손실은 무가중이므로 두 선의 차이는 가중 방식의 영향도 포함한다.

![XGBoost 개발과 중첩 혼동행렬](experiments/xgb_v4/artifacts/figures/confusion.png)

### 10.7 각도 학습량만 줄인 후속 대조

그림 14에서 손동작 검증 손실은 계속 감소했지만 각도 검증 손실은 초반 이후 증가했다. 이를 근거로 손동작은 200라운드로 유지하고 각도만 10·25·50·100라운드로 줄이는 대조를 추가했다. 4개 특징군과 깊이 2, 나머지 파라미터·개발 기록 5폴드는 유지했다. 16종·80회 실행 전에 [후속 계획](experiments/xgb_v4/ANGLE_ROUNDS_PLAN.md)을 기록했다.

추가 비교를 설계할 때 앞선 중첩·참가자 진단 결과까지 이미 확인한 상태였다. 따라서 이 단계는 개발 자료를 재사용한 탐색으로 분류했다. 기존 A/B 시험, 중첩 외부 평가와 참가자 진단은 다시 실행하지 않았다.

| 결합 특징의 각도 라운드 | 개발 시행 정확도 평균±SD | macro-F1 | 학습 정확도 |
|---:|---:|---:|---:|
| 10 | 52.47±9.70% | 0.5024 | 84.07% |
| 25 | 51.90±9.93% | 0.5024 | 88.08% |
| 50 | 52.35±8.09% | 0.5061 | 91.56% |
| 100 | 52.88±6.99% | 0.5087 | 95.23% |
| 200 | 52.24±9.03% | 0.5050 | 98.37% |

손동작 200·각도 100라운드의 `fusion_angle100`이 macro-F1 기준으로 선택됐다. 개발 정확도는 **52.88±6.99%**, F1은 **0.5087**이었다. 양쪽 200라운드보다 정확도는 0.64%p 높고 학습 정확도는 98.37%에서 95.23%로 낮아졌다. 다만 같은 개발 분할의 독립 LDA 54.65%, F1 0.5138에는 못 미쳤다. 각도 학습량을 줄인 효과는 작았고, 손동작이 같으면서 각도만 틀린 오류가 722건 중 554건으로 남았다.

![각도 학습량 비교](experiments/xgb_v4/artifacts/figures/angle_rounds.png)

*그림 17. 네 특징군에서 각도 학습량만 바꾼 개발 정확도 평균. 손동작은 200라운드로 고정했다. 각 특징의 200라운드 점은 앞선 결과를 재사용했다. 후보 선택 기준은 macro-F1이며, 검증 손실이 가장 낮은 라운드와 같을 필요는 없다.*

추가 80회의 합산 학습 시간은 43.32초였다. 기존 학습과 손동작 주변확률을 대조한 최대 차이는 2.38×10⁻⁷로, 바꾼 요인이 각도 학습량임을 확인했다. 이 단계는 별도 외부 평가를 수행하지 않았으므로 **52.88% 후보에 중첩 46.70%를 대응시키지 않는다**. 좁은 라운드를 반복 탐색하지 않고 이번 대조를 마무리했다. [전체 20개 대조 행과 검사](experiments/xgb_v4/ANGLE_ROUNDS_RESULTS.md)에 기존 기준 4개와 새 후보 16개의 결과를 함께 보존했다.

## 11. 강의 기준 C: 동일 기록 내 무작위 시행 분할

강의의 2초 분석 구간과 시행 무작위 분할을 별도 조건 C로 구현했다. 마커 뒤 1.5–3.5초에서 200 ms 창을 100 ms 간격으로 19개 만들고, 25개 시간영역 특징을 계산했다. 시작점 1.5초는 강의 예제의 가정이며 실제 동작 시작으로 확정된 시각은 아니다.

전체 1,920시행을 클래스별 무작위 5폴드로 나누고, 별도로 80/20 분할 1개도 평가했다. 시드는 42로 고정했다. 같은 시행의 창은 함께 배정했지만 같은 기록은 학습과 평가 양쪽에 포함된다. SVM은 RBF C=1, RF는 100트리를 사용했고 표준화는 학습 자료에서 계산했다. 이 실험은 추가 CNN 단계에서 수행했으며, 개발 전용 ML 탐색의 평가와 분리했다.

| 입력·집계 | 모델 | 지표 단위 | 5폴드 정확도 평균±SD | 80/20 정확도 |
|---|---|---|---:|---:|
| 창 학습 | SVM | 200 ms 창 | 48.55±0.43% | 49.99% |
| 19창 다수결 | SVM | 시행 | 80.89±1.30% | 82.55% |
| 창 학습 | RF | 200 ms 창 | 64.56±0.38% | 64.71% |
| 19창 다수결 | RF | 시행 | **96.20±0.89%** | **96.09%** |
| 19개 특징벡터 평균 후 학습 | SVM | 시행 | 89.01±3.06% | 88.54% |
| 19개 특징벡터 평균 후 학습 | RF | 시행 | 92.19±2.65% | 93.49% |

RF의 96.20±0.89%는 **강의 기준의 동일 기록 내 시행 분할에서 얻은 다수결 정확도**다. RF의 창 정확도 64.56%와의 차이는 시행별 집계 효과를 보여준다. 특징벡터를 먼저 평균한 RF는 92.19%로, 입력을 구성하는 방법에 따라서도 점수가 달라졌다.

그림 18은 C의 별도 80/20 분할에서 남은 오류를 보여준다.

![강의 기준 C 혼동행렬](experiments/generalization_v2/artifacts/figures/classroom_confusion.png)

*그림 18. C의 별도 80/20 평가 384시행에서 SVM과 RF의 19창 다수결을 비교했다. RF는 369/384개를 맞혔다. 같은 기록의 다른 시행이 학습 자료에 포함되며, A의 미관측 기록 평가와 표본 조건이 다르다.*

논문 초록의 RF 96.72±0.58%와 수치가 가깝지만, 논문 전문의 정확한 입력 위치·분할·집계 방식은 확인하지 못했다. C의 높은 점수는 A의 기록 일반화 개선이나 논문 재현 성공을 의미하지 않는다. B의 97.14%도 시간순 후속 시행이라는 별도 조건으로 유지한다. C의 고정 설정과 네 지표, 학습·추론 시간은 [실행 결과](experiments/generalization_v2/artifacts/results/classroom/all_results.json)에 있다.

| GPU Python | 3.10.12 |

초기 PC 실험은 기존 Python 환경과 사용자 GPU로 실행했다. 이 단계에는 패키지 추가 설치나 드라이버·OS 설정 변경이 없었다. 합성 자료로 출력 크기, 손실·기울기의 유한성, 체크포인트 저장·복원과 작은 표본의 학습 여부를 먼저 검사했다. 보완 실험의 합성 검사에서 발생한 float32 반올림 문제는 실제 데이터 학습 전에 수정했고, 원래 실패 로그는 별도로 보존했다.

자원 계획은 GPU 1개, CPU 최대 4스레드, 모델당 250,000개 이하의 파라미터, 학습 프로세스 GPU 메모리 8 GB 이하, 학습 예산 90분이었다. GPU 온도 85°C 이상, 여유 디스크 5 GB 미만, 비유한 수치 또는 데이터·분할 불일치가 발생하면 중단하도록 설정했다. 실제 CNN 학습 합계는 약 6.4분이었다. 폴드별 실행 시간은 저장 로그에 있지만, 기존 CPU 실험은 다른 환경에서 수행됐고 일부 시간은 학습과 평가를 함께 포함한다. 초기 단계에는 동일 장치의 모델별 단일 표본 100회 추론 시간을 확보하지 못했다. 추가 실험에서는 C의 모델별 학습·추론 시간과 ML 외부 저장 모델의 단일 특징 입력 추론 시간을 측정했다. 아래 표와 검사 파일은 측정에 포함한 계산 범위를 구분한다.

저장된 예측에서 GPU 80폴드와 CPU 50폴드의 점수를 다시 계산했다. 시험 인덱스 제외, 최적 epoch, 선택 결과, 데이터·코드·계획 해시와 앙상블 확률을 검사했다. 최종 CNN 8개 체크포인트의 정규화는 개발 데이터만 사용했으며, 복원 후 예측 확률의 최대 절대 오차는 **0.0**이었다. [전체 검사](reports/audit.json), [체크포인트 재실행](reports/checkpoint_replay.json), [자원 기록](reports/resources.json)에 결과가 있다.

공개본의 특징 재생성 경로도 검사했다. 70개 특징의 최대 절대 차이는 약 **8.9×10⁻¹⁶**이었고, 원파형 배열·분할·메타데이터 5개 파일은 기존 SHA-256과 모두 일치했다. 이어서 저장 예측으로 모든 CV 점수와 최종 비교표를 다시 계산했다. 이 검사는 완료된 학습 산출물의 재현성을 확인한 것이며, 새 학습이나 시험 후 튜닝은 포함하지 않았다. [공개본 재현 검사](reports/publication_reproduction_check.json)에 검사 범위를 명시했다.

4절의 문서 보완 분석에서는 A 개발 데이터 42개 원자료의 해시를 다시 확인하고, 시행별 RMS를 재계산했다. 보존된 시행 RMS와의 최대 절대 차이는 약 **5.6×10⁻¹⁷**이었다. 기존 분류 점수, 예측, 학습 코드와 선택 파일은 유지했다.

| 전통 ML | 827회 | CPU 최대 2작업×2스레드, 합산 학습 20.84분; 첫 완료부터 마지막 완료까지 약 14분 | 기존 SVM 5폴드 예측 재현, 외부 모델 15개 복원·학습 통계 확인 |

ML의 827회는 초기 비교 285, 내부 검증 345, 추가 대조 110, 외부 학습 15, 분할 진단 72회의 합계다. 독립·계층 구조가 내부에서 여러 분류기를 학습하므로 실제 하위 분류기의 개수와는 다르다. 학습 실패는 없었다. 학습 시간은 특징 생성·저장·보고서 시간을 제외한 값이며, 병렬 실행의 경과시간과 합산 시간을 구분했다.

ML은 기존 conda Python 3.13.9, scikit-learn 1.7.2, NumPy 2.3.5, SciPy 1.16.3에서 CPU로 실행했다. 추가 CNN은 기존 PyTorch 2.6.0+cu118의 CUDA 11.8 런타임을 사용했다. `nvidia-smi`의 CUDA 13.0 표시는 드라이버 호환 한계이며 실행 런타임 버전과 다르다. 표에 정리한 추가 CNN·ML 단계에는 새 패키지 설치, 드라이버 변경과 클라우드 연산이 없었다.

입력 해시, 개발 행만 포함됐는지, 기록·시행 분리와 학습 폴드의 표준화 통계를 검사했다. ML 외부 체크포인트의 예측은 저장 결과와 일치했고, 병렬 확률 합산의 최대 절대 차이는 2.22×10⁻¹⁶이었다. 이 추론 시간은 이미 계산한 특징 하나를 입력한 시간으로, 특징 추출을 포함하지 않는다. C의 입력은 창 또는 시행 평균 특징이므로 두 경우의 추론 1회도 구분했다.

근거는 [추가 CNN 검사](experiments/generalization_v2/artifacts/reports/final_checkpoint_verification.json), [ML 입력 검사](experiments/ml_v3/artifacts/reports/initial_verification.json), [ML 모델 복원 검사](experiments/ml_v3/artifacts/reports/outer_verification.json), [ML 자원 기록](experiments/ml_v3/artifacts/reports/resources.json)에 있다. 보고서 정리 과정에서는 기존 결과·모델 파일 2,850개의 해시가 유지됐고, 추가 실험 문서의 상대 링크 110개와 그림 13개를 검사했다. 루트 통합 문서의 검사는 이 기록과 별도로 남겼다.

### XGBoost 환경과 검사

후속 XGBoost는 기존 base 환경을 읽어 사용하는 별도 venv에 공식 PyPI의 `xgboost==3.0.5`와 의존 패키지 `nvidia-nccl-cu12==2.32.3`을 설치했다. 설치 전후 기존 base의 554개 패키지가 같음을 확인했다. Python 3.13.9, XGBoost CUDA 12.8 빌드, TITAN Xp, 드라이버 580.178.04에서 `device=cuda:0` 사용을 매 학습마다 확인했다. 설치 wheel의 출처·SHA-256과 환경 정보는 [환경 기록](experiments/xgb_v4/artifacts/reports/environment.json)에 있다.

총 504회는 개발 비교 120, 내부 검증 360, 외부 평가 5, 고정 모델 진단 18, 전체 개발 대표 학습 1회의 합계다. 합산 fit 시간은 10.44분이었다. GPU 1작업·CPU 2스레드로 순차 실행했고, 각 fit 전후 표본에서 최고 온도는 80°C, 장치 전체 메모리는 864 MiB였다. 이는 연속 측정한 최대값은 아니다. fit 시간에는 고정 라운드별 검증 손실 계산이 포함되고 특징 추출·파일 저장은 제외된다.

실제 데이터 학습 실패는 0회였다. 사전 합성 검사에서는 저장 모델이 기본 CPU로 복원되어 GPU 확률과 최대 1.19×10⁻⁷ 차이가 났다. 예측 라벨은 같았고, CUDA 장치를 명시한 복원에서는 오차가 0이었다. 이 실패와 수정을 보존한 뒤 실제 학습을 시작했다.

평가 503회의 점수를 저장 예측에서 다시 계산하고 개발 행·기록/시행 분리·입력 해시·선택 시각을 검사했다. 외부 저장 모델 5개는 CUDA 복원 후 확률이 완전히 일치했다. [검사 결과](experiments/xgb_v4/artifacts/reports/verification.json)와 [자원 기록](experiments/xgb_v4/artifacts/reports/resources.json)에 범위를 명시했다. 원신호·특징 행렬·UBJ 모델은 공개본에서 제외했다. 후속 각도 학습량 비교는 80회를 추가해 총 584회이며, 80회의 지표와 손동작 확률 불변을 별도로 검사했다. 보고서 생성 중 같은 이름의 이전 모듈을 참조한 오류 1건은 import 경로를 명시하여 수정했다. 학습·선택·수치에는 영향이 없었다.

## 14. 재현 방법

### 14.1 기존 공개 결과

아래 명령은 이 PC에서 확인한 기존 환경을 사용하며 패키지를 설치하지 않는다. GPU용 Python에는 PyTorch 2.6/cu118, NumPy와 pandas가, CPU용 Python에는 scikit-learn, SciPy, pandas와 matplotlib가 필요하다. 다른 PC에서는 12절의 버전을 기준으로 호환 환경을 준비한다.

```bash
git clone https://github.com/KyunghoCha/semg-arm-motion-coursework.git
cd semg-arm-motion-coursework

# 이 PC에서 확인한 기존 Python 환경
GPU_PYTHON=/usr/bin/python3
CPU_PYTHON="$(conda info --base)/bin/python"

$GPU_PYTHON run.py download
$CPU_PYTHON run.py features
$GPU_PYTHON run.py prepare
$GPU_PYTHON run.py self-check
$GPU_PYTHON run.py gpu-cv
$GPU_PYTHON run.py gpu-extension-cv
$CPU_PYTHON run.py cpu-cv

# 검증과 모델 선택을 완료한 뒤 최종 평가
$GPU_PYTHON run.py gpu-final
$CPU_PYTHON run.py cpu-final
$CPU_PYTHON run.py report
$GPU_PYTHON run.py verify-checkpoints
```

기본 작업 위치는 `runs/reproduction`이다. 별도 실행에는 모든 명령에 같은 `--workspace runs/새이름`을 붙인다. 기존 작업 폴더의 소스와 실행하려는 소스가 다르면 중단한다. 완료된 CV는 건너뛰며, 중단된 폴드는 처음부터 다시 학습한다. 코드나 설정이 다른 실험은 새 작업 폴더에서 수행한다.

원자료 다운로드는 약 977 MB, 전체 실행 폴더는 약 1.2 GB였으며, 실행 전 여유 공간 5 GB 이상을 검사한다. 실측 CNN 학습은 약 6.4분이었지만 데이터 준비와 CPU 검증에는 별도 시간이 들었다. 실행 시간과 수치의 재현 범위는 GPU, 라이브러리와 운영체제에 따라 달라질 수 있다.

그림 1의 집계 절차는 4절에 정의했다. `prepare`에서 생성한 `trial_audit.json`과 A 분할을 이용해 양쪽 각도가 개발 자료에 있는 21쌍을 찾고, 각 기록의 30개 시행 RMS 중앙값을 비교한다. 시간 곡선은 해당 원자료를 마커 기준 100 ms 비중첩 구간으로 나눈 뒤 각 시점의 시행 중앙값을 계산한다. 기존 `report` 명령은 분류 결과의 그림 2–6을 생성하며, 문서 보완용 그림 1은 이 별도 기술통계 절차로 작성했다.

## 15. 현재 결론과 후속 비교

초기 A에서는 1초 CNN이 같은 1초 집계 SVM보다 높았지만, 추가 CNN의 개발 개선은 재사용 시험에서 유지되지 않았다. 전통 ML에서는 손동작과 각도를 따로 학습하는 구조가 같은 개발 기록의 성능을 높였다. 독립 LDA의 개발 정확도는 54.65%였고, 별도로 고정한 23종 중첩 선택 절차는 40.52%였다. 두 결과는 평가 대상과 선택 역할이 다르다.

같은 기록 안에서 평가한 B의 시행 97.14%와 C의 RF 시행 96.20±0.89%는 반복 측정 조건 안의 성능을 보여준다. 기록을 바꾼 평가에서는 각도 오류와 참가자별 변동이 남았다. 이 때문에 현재 결과로 논문의 정확한 재현이나 새로운 기록·참가자에서의 90%대 성능을 확인하지 못했다.

채널 분석에서는 CH4 증가·CH5 감소 사례 4쌍을 확인했지만, 두 채널이 함께 증가한 경우는 16쌍이었다. 이두근·삼두근의 반응 방향을 구분해 살피는 질문은 유효했으나, 모든 참가자와 동작에 같은 진폭 규칙을 적용할 근거는 부족했다. 전극 위치, 세션 조건, 실제 관절각과 동기 동작 시점은 이 자료만으로 분리할 수 없다.

후속 XGBoost 24종의 개발 대표는 52.24±9.03%, 중첩 선택 절차는 46.70±8.40%였다. 독립 구조는 직접 분류보다 유리했지만 기존 독립 LDA의 개발 최고값을 넘지 못했고, 각도 오류와 참가자별 변동이 남았다. 각도 학습량을 줄인 후속 16종에서도 개발 대표는 52.88%로 기존 LDA를 넘지 못했다. 이번 단계까지 전통 ML 79종과 XGBoost 40종을 비교했다. 특징·구조·깊이·각도 학습량을 바꾼 결과를 종합하면, 각도 정보와 기록 조건을 분리할 새 측정 자료가 다음 판단에 필요하다. 후속 작업은 논문 전문의 조건 확인과 세션·전극 위치·동작 시점이 기록된 독립 자료 설계를 우선한다. 기존 점수와 실패 결과는 모두 유지한다.

논문 전문은 입력 위치·표본 구성·분할·평가 지표의 대응을 확인하는 데 필요하다. 독립 세션과 참가자 자료를 사전에 고정해야 그 범위의 일반화를 새로 평가할 수 있다. 현재 결론의 범위는 본문에 정의한 A/B/C와 기존 개발 자료를 재사용한 탐색이다.
